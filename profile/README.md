# OPO format

**OPO (Open Parametric Object)** is an open, vendor-neutral file format for parametric architectural objects: doors, windows, walls, stairs, curtain walls, equipment, and every other IFC element type. An `.opo` file is an IFCX document with an `opo::` extension, so it stays part of the IFC family.

| Repository | What it is |
|---|---|
| [opo](https://github.com/opo-format/opo) | The standard: spec, schemas, conformance tests, decisions, proposals |
| [opo-rs](https://github.com/opo-format/opo-rs) | Rust reference implementation and the `opo` command |
| [library](https://github.com/opo-format/library) | Objects, class templates, rule sets, materials and hatches |

Status: early draft. Curva is the first application implementing OPO.
