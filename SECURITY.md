# Security policy

OPO objects are meant to be safe to open from anyone: they cannot touch files, the network or the computer. If you find a way an `.opo` file, the `opo` command or a library object can do harm (code execution, resource exhaustion, data access), please do not open a public issue.

Report it privately with GitHub's **Report a vulnerability** button on the affected repository's Security tab. We aim to acknowledge reports within a week.
